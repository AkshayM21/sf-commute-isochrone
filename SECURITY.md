# Security policy

## Reporting a vulnerability

Please **do not** report suspected vulnerabilities in a public issue, pull
request, discussion, screenshot, or social post.

Use GitHub's private vulnerability-reporting flow for this repository:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Include a clear description, affected version or deployment, reproduction
   steps, impact, and any suggested mitigation.

If private reporting is not enabled or you cannot access it, do not publish the
details. Open a minimal public issue asking a maintainer to enable or provide a
private reporting channel; omit exploit details, credentials, personal data,
and affected addresses.

## Scope

Reports involving the public site, this repository, deployment configuration,
dependencies, exposed credentials, request handling, or privacy-sensitive
data are welcome. Please give maintainers a reasonable opportunity to assess
and remediate a report before disclosure.

## Operational notes

Never include API tokens, Cloudflare credentials, origin certificates, private
keys, or personal workplaces in a report. Redact them and describe only the
minimum information required to reproduce the issue.
